# c-cleanup
一个cc可以用的小skill，清理c盘
**不能直接作为"技能"使用。 /c-cleanup 这种技能机制（放在 .claude/skills/ 下、带 SKILL.md 格式）是 Claude Code 的约定，Trae 不认这个目录结构。                           但内容的 90% 可以复用：SKILL.md 本质就是一份写给 AI 的指令文档。你可以：                                                                                            - 把内容粘贴进 Trae 的自定义规则（rules）或自定义提示词里                                                             
  - 之后让 Trae 的 AI "按这份文档执行 C 盘清理





● 以下是 c-cleanup 技能的完整说明：

  ---

  C 盘清理技能（c-cleanup）说明

  功能定位

  针对 Windows 11，只清理可再生的缓存和临时数据，安全释放 C 盘空间。不动已安装软件、用户文档等有风险项目。

  会清理的内容
# Windows 磁盘清理清单
| # | 清理项 | 位置 | 说明 |
| --- | --- | --- | --- |
| 1 | Windows 更新下载缓存 | C:\Windows\SoftwareDistribution\Download | 通常最大头，可达 10+ GB。已装完的更新包残留，下次更新会重新下载，可安全删除 |
| 2 | 系统升级残留 | C:\$WINDOWS.~BT、C:\$WinREAgent | Windows 大版本升级时留下的临时文件，升级完成后无用 |
| 3 | 用户临时文件 | %TEMP% | 各软件运行时产生的临时文件（自动跳过 Claude 会话自身目录） |
| 4 | 系统临时文件 | C:\Windows\Temp | 系统级临时文件 |
| 5 | Edge 浏览器缓存 | Edge 缓存目录 | 网页缓存，可再生成 |
| 6 | 回收站 | 回收站 | 清空已删除文件 |
| 7 | npm 缓存 | npm 全局缓存 | 仅当安装了 npm 时执行，下次安装包会重新下载 |
| 8 | 旧组件备份（DISM） | WinSxS | 通过微软正规命令清理，耗时 10–30 分钟，释放 0–4 GB；释放 0 说明系统已无旧组件，属正常 |

 
  明确不会清理的（安全边界）

  - ❌ 已安装软件（Program Files）
  - ❌ 用户文档、图片、下载等个人文件
  - ❌ C:\Windows\Installer（删除会导致已装软件无法卸载/修复）
  - ❌ WinSxS 内容直接删除（只走 DISM 正规途径）
  - ❌ 搜索索引目录
  - ❌ Steam 缓存、微信/QQ 数据目录（涉及数据迁移，需用户确认后才动）

  执行流程

  1. 查看 C 盘当前空间
  2. （可选）扫描定位大目录占用
  3. 停止更新服务 → 清理更新缓存 → 重启服务
  4. 删除系统升级残留（存在才删）
  5. 清理各类临时文件 + 回收站 + npm 缓存
  6. 后台运行 DISM 组件清理
  7. 汇报清理前后空间对比

  效果参考

  上次在本机运行：释放约 6.9 GB（77.1 GB 已用 → 70.2 GB 已用），其中更新缓存是大头，DISM 释放 0（系统无旧组件）。

  安全性说明

  - 所有清理项都是可再生的缓存数据，删除后不影响系统功能和已装软件
  - 被正在使用的文件会静默跳过，不影响运行中的程序
  - 使用 \\?\ 长路径 API 处理超长路径，避免删除失败

 ● 在不同电脑或者不同与CC的AI上使用，怎么修改？

   A. 换电脑（仍用 Claude Code）

# 脚本修改核对表
| 位置 | 原文 | 需要改什么 |
| --- | --- | --- |
| 第 2 节末尾 | "已知环境信息：页面文件在 D 盘（不占 C）、休眠已关闭，无需重复检查这两项" | 必须改/删。这是本机专属假设。别的电脑休眠可能开着（hiberfil.sys 占 3–5 GB）、页面文件可能在 C 盘（占好几个 GB）。应改成：先检查这两项，或直接删掉这句 |
| 第 5 节 Edge 缓存路径 | $env:LOCALAPPDATA\Microsoft\Edge\... | 如果那台电脑用 Chrome/Firefox，路径要换（Chrome 是 Google\Chrome\User Data\Default\Cache）；多浏览器配置还要加 Profile 1 等目录 |
| 第 5 节跳过规则 | $_.Name -ne 'claude' | 同一台机器上如果 Claude Code 与别的 AI 工具并存，可保留；纯新电脑无影响，但建议同时跳过那台机器上其他 AI 工具自己的临时目录 |

  不需要改的：主流程、\\?\ 长路径删除技巧（Windows 通用）、DISM 命令、npm
  判断式写法（没装会自动跳过）、$env:TEMP/$env:LOCALAPPDATA 变量（自动适配用户名）。

  B. 换软件（如 Trae）

  1. 技能触发机制本身 —— 不能用。/c-cleanup 自动加载是 Claude Code 的机制，需要把 SKILL.md 内容转成 Trae
     的规则/自定义提示词粘贴进去。
  2. 跳过规则要改成 Trae 自己的目录 —— 原文跳过的 $env:TEMP\claude 是 Claude 的工作目录。Trae
     运行时也有自己的临时目录，如果不清掉它，它可能会在清理 %TEMP% 时误删自己正在用的文件，导致会话异常。需要在 Trae
     里先确认它的临时目录名，把跳过规则改成那个名字。
  3. "技能"格式本身 —— Trae 不认识 SKILL.md 的格式约定，贴过去的就是纯指令文本，AI 按文本执行即可，命令部分不用改。

  总结

  - 必须改：第 2 节的"页面文件在 D 盘、休眠已关闭"假设 → 换电脑时删掉或改为检查
  - 建议改：浏览器缓存路径（看目标电脑装了什么浏览器）、跳过规则（看目标软件的工作目录名）
  - 不用改：其余全部命令和流程（跨机器、跨软件通用）
